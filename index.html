FAIR File Namer

Research Data Namer
v1.0
On load this page reads the shared library.json next to it (operators, devices, labs, templates) and caches it, so it opens instantly and works offline; the master's changes are picked up on the next launch. Per-machine settings (default device, font/size, counters, recent names) stay in this browser only. Use the Manage tab to edit the library and Publish a new library.json.

The action buttons under a completed name:
  • Transfer with SafeTransfer – opens the SafeTransfer desktop app with the source and destination already filled in, to copy the acquired data to NASAC. Don't have it yet? Get SafeTransfer.
  • Rename existing files – batch-rename files from an earlier session to the FAIR name; a reversible rename manifest and a metadata sidecar are written into each folder. (Chrome/Edge only.)
  • Link recordings – give every file from one simultaneous recording (e.g. two-photon imaging plus a behavioural stream from other software) the same session id in each file's sidecar, so they group together. Scan-and-confirm or manual pick. (Chrome/Edge only.)
  • Download .md / Download .json – save the metadata as a Markdown block or as the JSON sidecar. The .json sidecar is also written into the destination folder when you click Copy file name (once its folder tree exists), so these are mainly for keeping a copy elsewhere.
